# Skill admission checklist

Lifecycle: planned → sourced → reviewed → approved → installed → verified.
Failed checks move to quarantined; superseded versions move to retired.
Record repository URL, immutable commit, license, reviewer, dependencies, permitted
inputs/outputs, tool permissions, egress, side effects, test command and evidence.
Review all bundled scripts and transitive dependencies before running anything.
A SKILL.md name alone does not establish compatibility or capability.
Install one reviewed skill at a time; use benign fixtures and both success and
failure tests. A count of 108 is a roadmap, never proof that 108 skills are loaded.
